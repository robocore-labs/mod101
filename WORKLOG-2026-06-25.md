## The arm architecture (current)

Standalone entry: `src/mod101_description/urdf/mod101.xacro` (tool-free for now —
tools deferred). Four build args:

| arg | default | meaning |
|---|---|---|
| `shoulder_ext_length` | 0.082 | upper-arm 2020 rail length, m (box primitive) |
| `elbow_ext_length` | 0.098 | forearm rail length, m |
| `shoulder_mount` | small | `small` (STS3215/3250) \| `big` (ST3120) |
| `elbow_mount` | small | same |

Macro: `mod101_macro.xacro` defines the **core** (base, wrist, camera links +
the connecting joints + the two extrusion boxes) and includes/invokes the
**joint modules** by mount:

```
urdf/modules/
  shoulder_small.xacro   mod101_shoulder_small(prefix)
  shoulder_big.xacro     mod101_shoulder_big(prefix)
  elbow_small.xacro      mod101_elbow_small(prefix)
  elbow_big.xacro        mod101_elbow_big(prefix)
```

Each module = prev link + servo + next link + the joints between them
(`fixed_servo_*` + the actuated pitch joint). Core wires
`joint_base → shoulder_rotation_link → … → arm_extrusion → elbow_link → … → forearm_extrusion`.

**Actuated joints (4):** `joint_base` (yaw, revolute ±90°), `joint_shoulder`
(pitch, 0..π), `joint_elbow` (pitch, 0..π), `joint_wrist_tilt` (continuous).
Wrist roll is **fixed** (export models it fixed; actuated 5th DOF + tool flange
deferred to the tool work). All actuated joints have
`<dynamics damping=1.0 friction=0.1>`.

**Canonical joint names**, fixed joints `fixed_<childlink>`, export axes kept
as-is (NO axis flips — flipping is what caused the earlier "explosion").

## How to run / test

**Gazebo (bare arm, ros2_control):**
```bash
colcon build --packages-select mod101_description mod101_gazebo mod101_control
source install/setup.bash
ros2 launch mod101_gazebo gazebo.launch.py                                  # small
ros2 launch mod101_gazebo gazebo.launch.py shoulder_mount:=big elbow_mount:=big
ros2 launch mod101_gazebo gazebo.launch.py shoulder_ext_length:=0.20
# command the arm:
ros2 topic pub /arm_controller/commands std_msgs/msg/Float64MultiArray "{data: [0.0, 1.0, 1.0, 0.0]}"
```

**Configurator (no colcon build needed — renders from src via the overlay):**
```bash
source /opt/ros/jazzy/setup.bash       # base ROS is enough
python3 configurator/server.py         # http://localhost:8000/
```
Endpoints: `/load` `/save` (4 args), `/urdf?…args…` (live render), `/nudge`
(GET/POST module offsets), `/masses`, `/pkg/<pkg>/meshes/<file>`, `/tool`.

**Quick render check (any combo), no browser:**
```bash
source /opt/ros/jazzy/setup.bash
xacro src/mod101_description/urdf/mod101.xacro shoulder_mount:=big elbow_mount:=big | check_urdf /dev/stdin
```
